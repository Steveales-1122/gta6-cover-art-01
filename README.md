Vice City Sunset — an offline web app that turns your photo and a caption into GTA 6-style multi-panel cover art (Vice City sunset/neon grade, bold lettering) and exports it as a PNG in 1080x1080, 1080x1350 or 1920x1080. Photos never leave your machine.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
